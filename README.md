# neuronalsimulation

It is a project in which AI is used to learn how to simulate using NEURON, HOC and python. Furthermore, learning how to code and plot biomedical simulations using AI. Meanwhile, also learning the meaning behind the results of the simulations and getting familiarize with git and git hub.

## Learning Roadmap

| Lesson | Topic | Goal |
| :---: | --------------------------- | --------------------------------- |
| ✅ **1** | Creating Sections | Build a neuron |
| ✅ **2** | Passive Membrane | Understand leak channels |
| **3** | Plotting Voltage | Visualize results |
| **4** | Active Channels | Generate action potentials |
| **5** | Hodgkin–Huxley Model | Understand Na⁺ and K⁺ currents |
| **6** | Multiple Current Injections | Study neuron responses |
| **7** | Cable Theory | Why dendrites attenuate signals |
| **8** | Synapses | Connect neurons together |
| **9** | Networks | Small neural circuits |
| **10** | Morphology Files | Import real reconstructed neurons |

- **cable theory**: how singnals travel through dendrites

- **synapses**: learn: ExpSyn, NetStim, NetCon

- **networks**: connect neurons with neurons and synapse, create a samll circuit 

- **morphology**: import a real morphology file: .swc, .asc, investigate a reconstructed neuron

- **.mod mechanisms**: start writing own mechanisms
